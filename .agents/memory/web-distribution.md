---
name: Web-first distribution
description: Product distribution and administrative access expectations.
---

The user wants the app published as a website on a domain, with a mobile-browser
installation popup for both Android and iOS. Learners and administrators install
and use the same web app.

**Why:** The user explicitly confirmed web publication plus mobile installation
as the intended distribution, including for administrators.

**How to apply:** Keep the administration interface usable on mobile browsers and
home-screen installations. Do not make app-store distribution or the separate Expo
companion a prerequisite for learning or administering the published website.

Installed mobile apps must use the mobile view, not the desktop-site layout.

**Why:** The user explicitly requested mobile presentation when using the installed app on phones.

**How to apply:** Keep mobile navigation available in phone landscape orientation and preserve safe-area spacing for both learners and administrators.

The user wants the web app prepared for deployment to ethiodeploy.com from its
GitHub repository.

**Why:** The user explicitly requested this external deployment destination.

**How to apply:** Keep external-host deployment preparation separate from Replit
publishing. Do not assume that hosting changes authorize moving existing data,
changing identity tenants, or activating the deferred payment gateway.
